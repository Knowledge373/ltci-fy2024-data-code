# データの列名と読み方

既存のCSV列名・列順・値を維持し、閲覧用Excelと機械処理用CSVの対応を示します。固定分析15列の定義・出典は [analysis_data_dictionary.csv](analysis_data_dictionary.csv) を参照してください。

## 月別表と分析入力の対応

| 月別CSV・Excelの列 | 分析入力の対応列 | 意味 |
|---|---|---|
| 研究ID | insref_id | FY2024内の研究照合キー。公的保険者番号や年度間追跡IDではありません。 |
| 都道府県 | prefecture_code | 月別表は名称、分析入力は全国01〜47のコードです。 |
| 保険者名 | — | 公的団体名。分析入力との照合には研究IDを使います。 |
| 対象年度 | fiscal_year | 2024年度（2024年4月〜2025年3月）。 |
| 2024-04〜2025-03 | 制度結合CSVの同名12列 | 分析月の通常納期あり1／なし0。月別収納額や実際の支払回数ではありません。 |
| 年間納期回数 | annual_installments | 現年度・定例・普通徴収の年間通常納期回数。12か月の納期あり指標の合計。 |
| 研究採用分類 | provisional_noneの日本語表示 | 仮算定の研究分類「あり／なし」。 |
| provisional_none | provisional_none | 仮算定なし1／あり0。 |

0と未確認は別概念です。今回の月列は全て0/1で、欠測を0に補っていません。休日繰越等による分析月への帰属と分類の来歴は [README_JA.md](README_JA.md) に記載しています。

月別表は19列、`support_selection/inputs/INSTITUTIONAL_JOIN_1573.csv` は研究ID・年度・全国都道府県コード・年間回数・仮算定なしフラグと12月列の17列です。`common_input_1573.csv` は別の固定15列分析入力で、月別表では置き換えません。

## 分析入力の尺度

- `*_fraction` と背景の `*_share` は0〜1の比率です。百分率表示は100倍、率差のpp表示も比率差を100倍します。
- `income_low3_share` の分母は17hのBF列です。02hの年度末被保険者数を分母に置き換えません。
- `ln_insured_end_fy_count` は年度末第1号被保険者数の自然対数です。
- `*_yen` は円です。原表の千円単位との換算は変数辞書に示しています。
- `insured_count_end_of_fiscal_year` は2025年3月31日の第1号被保険者全体で、普通徴収対象人数ではありません。
- `total_current_assessment_yen` は現年度の特別徴収と普通徴収の調定額合計で、滞納繰越を含む総額ではありません。

研究ID・全国都道府県コードは文字列として読みます。固定CSVをExcelで上書きすると桁や型が変わる場合があるため、再解析には元CSVを直接使ってください。

生成結果の係数・比較方向・クラスタIDは [出力の読み方](../OUTPUT_DICTIONARY_JA.md) を参照してください。
