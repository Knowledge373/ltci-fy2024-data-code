# FY2024月別納期と研究分類

研究対象1,573保険者について、FY2024（2024年4月〜2025年3月）の現年度・定例・普通徴収の月別納期を示す保存CSVです。公的団体名を保持しています。個人記録ではなく、完全匿名データでもありません。研究IDはinsref-xxxxで、公的保険者番号ではありません。

この公開用パッケージはCSVと同じ月別表の閲覧用Excelを同梱します。Excelは閲覧用、再解析にはCSVを使います。preview画像、Excel検査NDJSON、元資料一式は除外しました。元CSVの行・列・値・十進表記は一切変更していません。common_input_1573.csvは別の固定15列分析入力であり、月別CSVで置き換えないでください。

2024-04〜2025-03は各分析月に納期あり=1、なし=0です。0と未確認は別概念です。今回の保存値は全て0/1で、欠測を0に補っていません。実期限が共通暦で当該月の第1開庁日までなら原則として前月へ帰属する分析月です。土日・祝日・12月29日〜1月3日を閉庁日とし、法定期末が2025年1月5日の3保険者の第6期は1月に帰属させる保存済み例外があります。月別収納額・実納付回数・個人の納付実績を表しません。

研究採用分類の「あり／なし」は研究で採用した仮算定分類です。provisional_noneは1=なし、0=ありです。通常納期と制度的判断に基づく分類を含み、全てを原資料の明記だけから機械抽出したものではありません。行政の公式認定・新たな制度判定を意味しません。初回月から再分類していません。

母データの月別・分類には各保険者への直接公開URLが揃っていません。補足根拠台帳v6と新CSVを [evidence/20261021_v6/](evidence/20261021_v6/) に収録し、既存6CSVは旧v5の保存先を参照して、公開可能な保存出典URL・確認方法・判断理由と未確認点を整理しています。電話・メール原文や非公開の根拠資料は含まれず、このパッケージだけで全1,573件の原典を独立確認できる状態ではありません。

以下は元の閲覧用Excelの出典欄に保存されていた厚生労働省「介護保険事業状況報告（年報）」の公開参照です。財務・人数の出典であり、月別納期・制度分類の直接根拠ではありません。この整理作業ではリンク先の再取得・原典再調査はしていません。

- 財務14h：https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040491696&fileKind=0
- 人数02h：https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040491650&fileKind=0

人数は2025年3月31日の第1号被保険者全体、財務はFY2024年次フローです。普通徴収対象人数・月次財務と混同しないでください。固定CSVをExcelで開いて上書きすると約15桁精度・自動型変換により表記が変わる場合があります。再解析には元CSVを直接読み、研究ID・県コードを文字列として扱ってください。

本整理の静的確認では1,573件のID一対一対応、年度、12か月合計と年間回数、固定CSVとの年間回数・分類対応を検査しました。保存データの整合性確認であり、原典・分類の正しさや因果関係の保証ではありません。

変数辞書のA102・B0・prefecture_codes.csvは固定入力作成時の保存資料名です。これらの原作業ファイルを同梱するという意味ではありません。実行に必要な研究ID・制度変数・都道府県コード・背景変数はcommon_input_1573.csvに含まれます。

列の対応と尺度は [データの列名と読み方](HEADER_GUIDE_JA.md) にまとめています。閲覧用Excelの「読み方」シートにも月別0/1・仮算定分類・研究IDの説明を収録しています。
