パッケージのルートから、Python 3.12、NumPy 2.3.5、SciPy 1.17.0で実行します。

    python -B contrast_extension/run_cell16_additional_contrasts.py --output-dir /new/empty/output

出力先はソースの外側にある新規又は空のディレクトリを指定します。毎回固定入力から16セルモデルを計算し、`CELL16_ADDITIONAL_TWO_CONTRASTS.csv`、`ADDITIVE_CELL16_COMPARISON.csv` と数値・環境の検査記録を新規作成します。上の保存比較結果は新実行出力からそのまま収録したもので、実行を省略するためのキャッシュではありません。`*_display3` がS4Aの3桁表示に対応します。

`--freeze PATH` は実行者が用意する保護対象の事前記録、`--prior-results PATH` は過去結果との事後照合を行う任意指定です。どちらも通常の再現実行に不要で、過去値を推定の目標や計算入力に使いません。これらの個別監査用ファイルは同梱していません。

## 数値仕様と範囲

固定順序は `B9_cell16`＝9回なし−12回あり、`B10_cell16`＝10回なし−12回ありです。仮算定なしを1、ありを0とし、66列設計の0始まり索引でそれぞれ `c[11]=1, c[15]=-1`、`c[13]=1, c[15]=-1`、他は0です。1,573保険者、実在16セル、3つの単独保険者セル、4背景変数、47都道府県、等保険者重みを保持します。

既存CR2代数、固有値閾値1e-12、対比固有Satterthwaite自由度と多重性未調整の個別95％t区間を使います。`h_g=(c'G_g X_g L)'` は列ベクトルで、Hは66×47（部分化後16×47）、Pは47×47です。内部の点差・SE・区間は比率、pp表示は100倍、表示丸めは小数3桁のROUND_HALF_EVENです。共存県数を自由度又は有効クラスタ数とは扱いません。

full66、partial16及び残差射影による数値照合、66/50/16の階数検査、既存4対比の回帰検算を行います。射影経路は同じPython/SciPy環境内の別代数であり、新たなRパッケージの実行ではありません。加法モデルの再推定、全47県の除外階数検査、1,620回の削除再推定、支持集合の再選定、bootstrap、TOST又は旧全体入口の実行は含みません。低自由度・広い区間・0をまたぐ区間・符号反転等を理由に対比を除外しません。
